レッスンモード

上から順にクリアして「星に願いを」完奏を目指す段階レッスン。コード課題はチェッカー、曲課題はゲームが自動でセットされます。進捗は保存されます。

    下のチェッカーが自動でこのコードになっています。ジャン!と鳴らして○を集めよう。

    進行をつくる

    記法:「D:2」=拍数 / 「D*4」=鳴らす回数 / 「-」=1小節伸ばす / 「N.C.」=休み / 【見出し】=メモ(読み飛ばし)

    セクション単位のプリセット。BPM・カポも一緒にセットされます。

    コードをタップで末尾に追加。範囲の操作は、入力欄をドラッグ選択してから。

    追加する刻み
    選択範囲を(選択なし=全体)

    曲に登場するコード移動を回数順に表示。タップで反復セット(3周・BPM+5/周)を自動生成。

    刻み

    マイクOFFのままでもプレイできます(判定なしの流し練習モード)

    使えるコード:全ルート(♯・♭可)× メジャー / m / 7 / m7 / M7 / 6 / m6 / 9 / add9 / maj9 / sus2 / sus4 / 7sus4 / dim / dim7 / aug / m7b5。分数コード(A/C#等)はルート側で判定します。

    コードチェッカー

    カポ位置に連動したコード表。カードをタップして選び、マイクONで鳴らすと判定します。丸の色=指:●1人差し指 ●2中指 ●3薬指 ●4小指。コード間で同じ色を追うと指の移動先がわかります。

    —コードを選んでマイクをONに

    鳴らすと弦ごとに判定:緑=鳴ってる / 赤=鳴ってない / ×=弾かない弦。音名はカポ込みの実音です。「◯◯に近づいてます」=どこかの弦の音が欠けて別コードの響きになっている状態で、メッセージ内の弦が原因です。

    チューナー

    1本ずつ弦を鳴らしてください。合わせる時はカポなし、カポ装着後は「確認」に使います(目標音はカポ設定に連動)。
